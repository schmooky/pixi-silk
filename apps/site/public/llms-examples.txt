# pixi-silk: examples

> Smooth vector graphics for PixiJS v8. Every shape is an exact signed distance field, anti-aliased per pixel in the shader, so edges stay smooth at any zoom, rotation and device pixel ratio without MSAA.

pixi-silk 1.0.0 is an MIT-licensed TypeScript library. It needs pixi.js ^8.6 as a peer dependency, and a browser with WebGL2 or WebGPU.

Site: https://pixi-silk.schmooky.dev
Repository: https://github.com/schmooky/pixi-silk
Package: https://www.npmjs.com/package/pixi-silk

This file holds whole screens built with pixi-silk, with the full source of every demo. The demos run in the docs demo runner: `defineDemo({ setup({ stage, params, tick }) })`. In your app, `stage` is `app.stage` (or a container on it), `params` are your own values and `tick(fn)` is `app.ticker.add`.

- [llms-full.txt](https://pixi-silk.schmooky.dev/llms-full.txt): core, paint and rendering: guides and API, SilkGraphics first.
- [llms-ui.txt](https://pixi-silk.schmooky.dev/llms-ui.txt): text, layout, UI widgets and the editor kit: guides and API.

```ts
import { Container, Text, type TextStyleFontWeight } from 'pixi.js';
import { damp, SilkGraphics } from 'pixi-silk';
import { defineDemo } from './runtime';

// A monochrome weather dashboard. Static shapes redraw only while the theme fades, the needle,
// compass and sunrise arrow move on their own layer every frame.

const W = 390;
const H = 900;
const MONO = '"JetBrains Mono", "SF Mono", Menlo, Consolas, monospace';

interface Palette {
    bg: number;
    card: number;
    disc: number;
    onDisc: number;
    ink: number;
    faint: number;
}

const LIGHT: Palette = {
    bg: 0xdcdedb,
    card: 0xebecea,
    disc: 0x1d1d1d,
    onDisc: 0xf2f2f2,
    ink: 0x1d1d1d,
    faint: 0x9a9c99,
};
const DARK: Palette = {
    bg: 0x000000,
    card: 0x1e1f21,
    disc: 0xe9eaea,
    onDisc: 0x111111,
    ink: 0xf2f2f2,
    faint: 0x6a6b6d,
};

const mix = (a: number, b: number, t: number) => {
    const ch = (s: number) => Math.round(((a >> s) & 255) + (((b >> s) & 255) - ((a >> s) & 255)) * t) << s;

    return ch(16) | ch(8) | ch(0);
};
const blend = (t: number): Palette => ({
    bg: mix(LIGHT.bg, DARK.bg, t),
    card: mix(LIGHT.card, DARK.card, t),
    disc: mix(LIGHT.disc, DARK.disc, t),
    onDisc: mix(LIGHT.onDisc, DARK.onDisc, t),
    ink: mix(LIGHT.ink, DARK.ink, t),
    faint: mix(LIGHT.faint, DARK.faint, t),
});

// layout: two columns of cards under the hero row
const COL = [20, 205];
const CARD_W = 165;
const CARD_H = 165;
const ROW = [330, 515, 700];
const hair = (color: number, alpha = 1) => ({ width: 1.25, color, alpha });

type Role = 'ink' | 'onDisc' | 'faint';

export default defineDemo({
    title: 'Weather card',
    size: [W, H],
    // phones: the same card, as tall as the frame width allows, with no text under 12 px
    phone: { size: [W, H] },
    controls: {
        theme: { type: 'select', label: 'theme', options: ['light', 'dark'], value: 'dark' },
    },
    setup({ stage, params, tick, phone }) {
        const base = new SilkGraphics();
        const live = new SilkGraphics();
        const texts = new Container();
        const labels: [Text, Role][] = [];
        let fade = params.theme === 'dark' ? 1 : 0;
        let drawnFade = -1;

        stage.addChild(base, live, texts);

        const text = (
            value: string,
            x: number,
            y: number,
            size: number,
            role: Role,
            anchor = 0,
            weight: TextStyleFontWeight = '400',
        ) => {
            // a phone frame shows the card at about 0.9: the small labels grow to stay readable
            const t = new Text({
                text: value,
                style: {
                    fill: 0xffffff,
                    fontFamily: MONO,
                    fontSize: phone ? Math.max(12, size) : size,
                    fontWeight: weight,
                    letterSpacing: size * 0.08,
                },
            });

            t.anchor.set(anchor, 0.5);
            t.position.set(x, y);
            texts.addChild(t);
            labels.push([t, role]);
        };

        // header
        text('BROADGATE', W / 2, 92, 17, 'ink', 0.5);
        // hero
        text('12°', 115, 204, 66, 'onDisc', 0.5, '300');
        text('H:14° L:9°', 115, 254, 13, 'onDisc', 0.5);
        text('AIR QUALITY  21', 228, 162, 13, 'ink');
        text('Fair', 228, 184, 13, 'ink');
        text('UV INDEX 02', 228, 254, 13, 'ink');
        text('Low', 228, 276, 13, 'ink');
        // card titles and values
        const card = (col: number, row: number, title: string, sub: string, value: string, unit = '') => {
            const x = COL[col] + 16;
            const y = ROW[row];

            text(title, x, y + 22, 11, 'ink');
            if (sub) text(sub, x, y + 38, 11, 'ink', 0, '700');
            text(value, x, y + CARD_H - 26, 26, 'ink', 0, '300');
            if (unit) text(unit, x + value.length * 17 + 4, y + CARD_H - 22, 10, 'ink');
        };

        card(0, 0, 'AIR QUALITY', 'Fair', '21');
        card(1, 0, 'HUMIDITY', '', '79%');
        card(0, 1, 'WIND SPEED', '', '7', 'MPH');
        card(1, 1, 'UV INDEX', 'Low', '02');
        card(0, 2, 'SUNRISE', '', '06:11');
        text('N', COL[0] + CARD_W / 2, ROW[1] + 56, 9, 'ink', 0.5, '700');
        text('FEELS LIKE', COL[1] + CARD_W / 2, ROW[2] + 60, 12, 'onDisc', 0.5);
        text('11°', COL[1] + CARD_W / 2, ROW[2] + 100, 46, 'onDisc', 0.5, '300');

        const drawBase = (p: Palette) => {
            const g = base.clear();

            g.rect(0, 0, W, H).fill(p.bg);
            menuIcon(g, 28, 92, p.ink);
            gearIcon(g, W - 38, 92, p);
            g.circle(115, 218, 90).fill(p.disc);
            g.pill(212, 130, 160, 74).fill(p.card);
            g.pill(212, 222, 160, 74).fill(p.card);
            g.line(20, 318, W - 20, 318).stroke(hair(p.ink));
            for (const [col, row] of [
                [0, 0],
                [1, 0],
                [0, 1],
                [1, 1],
                [0, 2],
            ]) {
                g.roundRect(COL[col], ROW[row], CARD_W, CARD_H, 14).fill(p.card);
            }
            gaugeFace(g, COL[0] + CARD_W / 2, ROW[0] + 108, p);
            g.circle(COL[1] + CARD_W / 2, ROW[0] + 82, 46).stroke(hair(p.ink, 0.6));
            g.circle(COL[1] + CARD_W / 2, ROW[0] + 82, 37).fill(p.disc);
            compassFace(g, COL[0] + CARD_W / 2, ROW[1] + 92, p);
            uvStack(g, COL[1] + CARD_W / 2, ROW[1] + 120, p);
            sunriseFace(g, COL[0] + CARD_W / 2, ROW[2] + 92, p);
            g.circle(COL[1] + CARD_W / 2, ROW[2] + CARD_H / 2, 82).fill(p.disc);
        };

        tick((t, dt) => {
            fade = damp(fade, params.theme === 'dark' ? 1 : 0, 6, dt);
            const p = blend(fade);

            if (Math.abs(fade - drawnFade) > 0.001) {
                drawBase(p);
                drawnFade = fade;
                for (const [label, role] of labels) label.tint = p[role];
            }
            const g = live.clear();

            gaugeNeedle(g, COL[0] + CARD_W / 2, ROW[0] + 108, 0.28 + Math.sin(t * 0.7) * 0.04, p.ink);
            compassNeedle(g, COL[0] + CARD_W / 2, ROW[1] + 92, 0.45 + Math.sin(t * 0.9) * 0.08, p.onDisc);
            sunriseArrow(g, COL[0] + CARD_W / 2, ROW[2] + 92, Math.sin(t * 1.6) * 2.5, p.ink);
        });

        return undefined;
    },
});

function menuIcon(g: SilkGraphics, x: number, y: number, color: number) {
    for (let i = -1; i <= 1; i++) {
        g.circle(x, y + i * 7, 1.5).fill(color);
        g.line(x + 6, y + i * 7, x + 24, y + i * 7).stroke({ width: 1.5, color, cap: 'round' });
    }
}

function gearIcon(g: SilkGraphics, x: number, y: number, p: Palette) {
    g.star(x, y, 8, 13, 10.5, 0, 1.2).fill(p.ink);
    g.circle(x, y, 8.5).fill(p.bg);
    g.circle(x, y, 4).fill(p.ink);
    g.circle(x, y, 2.6).fill(p.bg);
}

function gaugeFace(g: SilkGraphics, cx: number, cy: number, p: Palette) {
    const r = 50;

    g.line(cx - 72, cy, cx + 72, cy).stroke(hair(p.ink));
    g.arc(cx, cy, r, Math.PI, Math.PI * 2).stroke(hair(p.ink));
    for (let i = 0; i <= 16; i++) {
        const a = Math.PI + (i / 16) * Math.PI;
        const inner = i % 4 === 0 ? r - 9 : r - 5;

        g.line(cx + Math.cos(a) * inner, cy + Math.sin(a) * inner, cx + Math.cos(a) * r, cy + Math.sin(a) * r).stroke(
            hair(p.ink),
        );
    }
}

function gaugeNeedle(g: SilkGraphics, cx: number, cy: number, value: number, color: number) {
    const a = Math.PI + value * Math.PI;
    const tipX = cx + Math.cos(a) * 44;
    const tipY = cy + Math.sin(a) * 44;
    const head = 7;

    g.line(cx, cy, tipX, tipY).stroke({ width: 1.5, color, cap: 'round' });
    for (const side of [-0.45, 0.45]) {
        g.line(tipX, tipY, tipX - Math.cos(a + side) * head, tipY - Math.sin(a + side) * head).stroke({
            width: 1.5,
            color,
            cap: 'round',
        });
    }
}

function compassFace(g: SilkGraphics, cx: number, cy: number, p: Palette) {
    g.circle(cx, cy, 44).stroke(hair(p.ink));
    g.circle(cx, cy, 30).fill(p.disc);
    g.regularPoly(cx, cy - 47, 3.5, 3, 0, 0.5).fill(p.ink);
}

function compassNeedle(g: SilkGraphics, cx: number, cy: number, angle: number, color: number) {
    const dx = Math.sin(angle) * 24;
    const dy = -Math.cos(angle) * 24;

    g.line(cx + dx, cy + dy, cx - dx, cy - dy).stroke({ width: 1.4, color, cap: 'round' });
    const back = Math.atan2(-dy, -dx);

    for (const side of [-0.5, 0.5]) {
        g.line(cx - dx, cy - dy, cx - dx - Math.cos(back + side) * 6, cy - dy - Math.sin(back + side) * 6).stroke({
            width: 1.4,
            color,
            cap: 'round',
        });
    }
}

function uvStack(g: SilkGraphics, cx: number, cy: number, p: Palette) {
    // `cy` is the shared base line: each ellipse sits on it, the tallest faintest
    for (let i = 0; i < 5; i++) {
        const ry = 36 - i * 6.5;

        g.ellipse(cx, cy - ry, 46, ry).stroke(hair(p.ink, 0.22 + i * 0.13));
    }
    g.ellipse(cx, cy, 46, 4.5).stroke({ width: 1.8, color: p.ink });
}

function sunriseFace(g: SilkGraphics, cx: number, cy: number, p: Palette) {
    g.line(cx - 72, cy, cx + 72, cy).stroke(hair(p.ink));
    g.arc(cx, cy, 52, Math.PI, Math.PI * 2).stroke(hair(p.ink, 0.45));
    g.arc(cx, cy, 40, Math.PI, Math.PI * 2).stroke({ width: 1.6, color: p.ink });
    g.line(cx - 52, cy + 10, cx + 52, cy + 10).stroke(hair(p.ink, 0.7));
    g.line(cx - 34, cy + 18, cx + 34, cy + 18).stroke(hair(p.ink, 0.7));
    g.line(cx - 12, cy + 26, cx + 12, cy + 26).stroke(hair(p.ink, 0.7));
}

function sunriseArrow(g: SilkGraphics, cx: number, cy: number, lift: number, color: number) {
    const top = cy - 26 - lift;

    g.line(cx, cy - 8, cx, top).stroke({ width: 1.4, color, cap: 'round' });
    g.line(cx, top, cx - 5, top + 6).stroke({ width: 1.4, color, cap: 'round' });
    g.line(cx, top, cx + 5, top + 6).stroke({ width: 1.4, color, cap: 'round' });
}
```

```ts
import { Container, Text, type TextStyleFontWeight, type TextStyleOptions } from 'pixi.js';
import { damp, ease, SilkGraphics } from 'pixi-silk';
import { Odometer } from 'pixi-silk/ui/odometer';

// A finance bento board. Every tile is its own container: it slides in on load, lifts on hover,
// and animates its numbers and bars once it has landed.

const W = 720;
const H = 900;
const GAP = 19;
const COL_W = (W - GAP * 4) / 3;
const col = (i: number) => GAP + i * (COL_W + GAP);
const SANS = 'Inter, "Helvetica Neue", system-ui, sans-serif';

const C = {
    page: 0x2a2a2a,
    orange: 0xf28a2e,
    orangeDeep: 0xd9762a,
    ink: 0x111111,
    stone: 0x8f8f8b,
    mist: 0xd9d9d6,
    paper: 0xf2f2f0,
    olive: 0x7f8b6c,
    oliveDeep: 0x5e6950,
    slate: 0x5a5a5a,
    arrow: 0xc4c4c4,
    clay: 0x7d5546,
    taupe: 0x857a5c,
    sand: 0xc8b88d,
    donut: 0x4a4a4a,
};

interface Tile {
    view: Container;
    /** 0..1 entrance progress, starts after `delay`. */
    enter: number;
    delay: number;
    lift: number;
    hover: boolean;
    /** Redraws the animated parts with the eased entrance value. */
    update?: (p: number, t: number) => void;
}

type Label = (
    text: string,
    size: number,
    color: number,
    weight?: TextStyleFontWeight,
    extra?: TextStyleOptions,
) => Text;

/** Text in the board's font. Sizes under `floor` grow to it, and so does their line height. */
const labelWithFloor =
    (floor: number): Label =>
    (text, size, color, weight = '500', extra = {}) => {
        const k = Math.max(1, floor / size);
        const lineHeight = extra.lineHeight === undefined ? undefined : extra.lineHeight * k;

        return new Text({
            text,
            style: { fill: color, fontFamily: SANS, fontSize: size * k, fontWeight: weight, ...extra, lineHeight },
        });
    };

// phones: two columns instead of three, shown at about 0.73, so labels grow to 15 to stay readable
const PHONE_W = 2 * COL_W + 3 * GAP;
const PHONE_H = 1396;
/** Tile positions on phones: column and top. */
const PHONE: Record<string, [number, number]> = {
    orange: [0, 20],
    volume: [0, 279],
    bars: [0, 628],
    clock: [0, 1022],
    send: [1, 20],
    research: [1, 209],
    currency: [1, 698],
    arrow: [1, 907],
    donut: [1, 1176],
};

function tile(x: number, y: number, w: number, h: number, fill: number, delay: number, radius = 10): Tile {
    const view = new Container();
    const bg = new SilkGraphics();

    bg.roundRect(0, 0, w, h, radius).fill(fill);
    view.addChild(bg);
    view.position.set(x, y);
    view.eventMode = 'static';
    view.hitArea = { contains: (px, py) => px >= 0 && py >= 0 && px <= w && py <= h };

    const t: Tile = { view, enter: 0, delay, lift: 0, hover: false };

    view.on('pointerover', () => (t.hover = true));
    view.on('pointerout', () => (t.hover = false));

    return t;
}

function place(child: Container, x: number, y: number, ax = 0, ay = 0) {
    if ('anchor' in child) (child as Text).anchor.set(ax, ay);
    child.position.set(x, y);

    return child;
}
```

```ts
function hot(v: number): number {
    const stops = [0x1a2cff, 0xff1e1e, 0xffffff];
    const x = Math.min(1, Math.max(0, v)) * (stops.length - 1);
    const i = Math.min(stops.length - 2, Math.floor(x));
    const t = x - i;
    const ch = (s: number) => Math.round(((stops[i] >> s) & 255) * (1 - t) + ((stops[i + 1] >> s) & 255) * t) << s;

    return ch(16) | ch(8) | ch(0);
}

function drawCells(g: SilkGraphics, t: number) {
    g.clear();
    const hotX = 0.22 + Math.sin(t * 0.4) * 0.05;
    const hotY = -0.18 + Math.cos(t * 0.33) * 0.04;

    for (let j = 0; j < GRID; j++) {
        for (let i = 0; i < GRID; i++) {
            const x = CX - RADIUS + i * CELL;
            const y = CY - RADIUS + j * CELL;
            const u = (x + CELL / 2 - CX) / RADIUS;
            const v = (y + CELL / 2 - CY) / RADIUS;

            if (u * u + v * v > 1) continue;
            // a soft grey body, brighter towards its lower right, with a slow ripple

                Math.max(0, 1 - Math.hypot((u - 0.05) / 0.9, (v - 0.15) / 0.75)) *
```

```ts
const W = 760;

/** A beam pinched in the middle: full height `h` at both ends, `waist` at the centre. */
function hourglass(g: SilkGraphics, cx: number, cy: number, w: number, h: number, waist: number): SilkGraphics {
    const x0 = cx - w / 2;
    const x1 = cx + w / 2;
    const t = cy - h / 2;
    const b = cy + h / 2;

    return g
        .beginPath()
        .moveTo(x0, t)
        .bezierCurveTo(x0 + w * 0.22, cy - h * 0.1, cx - w * 0.12, cy - waist / 2, cx, cy - waist / 2)
        .bezierCurveTo(cx + w * 0.12, cy - waist / 2, x1 - w * 0.22, cy - h * 0.1, x1, t)
        .lineTo(x1, b)
        .bezierCurveTo(x1 - w * 0.22, cy + h * 0.1, cx + w * 0.12, cy + waist / 2, cx, cy + waist / 2)

    t.anchor.set(anchorX, 0);
    t.position.set(x, y);

    return t;
```

# Charts

URL: https://pixi-silk.schmooky.dev/docs/charts/
Area: Examples

> Build area and line charts with monotone smoothing that never overshoots, fading gradient fills, dashed guides, bars and dots in SilkGraphics.

pixi-silk has no chart component. It gives you the pieces a chart is drawn with: filled areas,
smoothed series, dashed guides and bars. The experiments at the end of this page are complete chart
widgets built from them.

Demo sources run in the docs demo runner, `defineDemo({ setup({ stage, params, tick }) })`. In your own app, `stage` is `app.stage` (or a container on it), `params` holds the values of the demo controls, and `tick(fn)` is `app.ticker.add`, with `t` and `dt` in seconds.

Live demo `area-chart` (source):

```ts
import { SilkGraphics, vertical } from 'pixi-silk';
import { defineDemo } from './runtime';

const FILL = vertical(
    [
        [0, 0x0a84ff, 0.55],
        [1, 0x0a84ff, 0],
    ],
    { easing: 'smooth' },
);

export default defineDemo({
    title: 'Area chart',
    size: [480, 220],
    controls: {
        smooth: { type: 'toggle', label: 'monotone smoothing', value: true },
        dots: { type: 'toggle', label: 'dots', value: true },
    },
    setup({ stage, params, tick }) {
        const g = new SilkGraphics();
        const data = Array.from({ length: 13 }, (_, i) => 90 + Math.sin(i * 0.9) * 40);

        stage.addChild(g);
        tick((t) => {
            const pts = data.flatMap((v, i) => [30 + i * 35, v + Math.sin(t * 1.5 + i) * 12]);
            const smooth = params.smooth ? ('monotone' as const) : undefined;

            g.clear();
            for (const y of [40, 90, 140]) g.line(20, y, 460, y).stroke({ width: 1, color: 0x3a3a3c, dash: [2, 4] });
            g.line(20, 190, 460, 190).stroke({ width: 1, color: 0x636366 });
            // area between the series and a baseline; stroke() right after draws its top line
            g.area(pts, 190, { smooth }).fill(FILL).stroke({ width: 2.5, color: 0x0a84ff, cap: 'round' });
            if (params.dots)
                for (let i = 0; i < pts.length; i += 2)
                    g.circle(pts[i], pts[i + 1], 3.5)
                        .fill(0xffffff)
                        .stroke({ width: 2, color: 0x0a84ff });
        });
    },
});
```

### Fill the area under a series

```ts
const FILL = vertical(
    [
        [0, 0x0a84ff, 0.55],
        [1, 0x0a84ff, 0],
    ],
    { easing: 'smooth' },
);

g.area(points, 190, { smooth: 'monotone' }).fill(FILL).stroke({ width: 2.5, color: 0x0a84ff, cap: 'round' });
```

`area(points, lower)` fills the region between a series and a y baseline. Pass a second series as
`lower` to fill the band between two series. The `stroke()` right after it draws the series line on
top, from the same smoothed points.

The area is split into vertical columns that share their edges exactly. A translucent fill stays
even, with no seams between columns.

| Option | Default | What it does |
|---|---|---|
| `smooth` | `false` | `'monotone'` draws a smooth curve through the points |
| `step` | `2` | Sample spacing of the smoothed curve, in local units |

### Smoothing that keeps the data

`smooth: 'monotone'` never overshoots. It uses Steffen's method, like d3's `curveMonotoneX`. Peaks
stay on the data points and flat runs stay flat. `polyline()` also takes `smooth: 'catmull'`, which
overshoots, so keep it for decorative curves. `monotoneX()` returns the resampled points if you need
them for hit testing or labels.

### Guides, bars and dots

```ts
for (const y of [40, 90, 140]) g.line(20, y, 460, y).stroke({ width: 1, color: 0x3a3a3c, dash: [2, 4] });
for (const [i, v] of values.entries()) g.roundRect(20 + i * 12, 190 - v, 8, v, 3).fill(0xffd60a);
for (const [x, y] of points) g.circle(x, y, 3.5).fill(0xffffff).stroke({ width: 2, color: 0x0a84ff });
```

Guides are dashed lines, bars are rounded rects and dots are circles with a stroke. All of them go
into the same `SilkGraphics` as the series.

### One gradient across many bars

By default a gradient fits each shape's box. With `units: 'local'` it uses the coordinates of the
graphics instead, so a row of bars samples one continuous ramp:

```ts
const HEAT = linear(
    [
        [0, 0x30d158],
        [0.5, 0xffd60a],
        [1, 0xff453a],
    ],
    { units: 'local', from: [0, 190], to: [0, 40] },
);

for (const [i, v] of values.entries()) g.roundRect(20 + i * 12, 190 - v, 8, v, 3).fill(HEAT);
```

A tall bar then reaches the red end and a short one stays green. [Gradients](https://pixi-silk.schmooky.dev/docs/gradients/)
covers the other gradient kinds and options.

### Where it stops

There are no axes, scales, tick generation or tooltips. Map your data to pixels yourself, or with a
scale library such as d3-scale, and draw labels with [text](https://pixi-silk.schmooky.dev/docs/text/).

# FAQ

## How do I draw charts with PixiJS?

Use `area(points, baseline, { smooth: 'monotone' })` for filled areas, `polyline` for lines and `roundRect` for bars. Monotone smoothing never overshoots the data.

## Can I copy the showcase widgets into my app?

Yes, they are MIT like the library. They are site code, not exports, so copy the lab file you need from the repository.
