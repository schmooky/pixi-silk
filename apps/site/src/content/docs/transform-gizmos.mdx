## Three pieces

```ts
import { TransformGizmo } from 'pixi-silk/ui/gizmo';
import { SelectionOutline } from 'pixi-silk/ui/outline';
import { SnapEngine, SnapGuides } from 'pixi-silk/ui/snap';
```

Each one works alone. Put the outline and the gizmo in an overlay above your scene: they read the
target's transform every frame, so they follow it wherever it sits in the tree.

## Transform gizmo

```ts
import { Container } from 'pixi.js';
import { TransformGizmo } from 'pixi-silk/ui/gizmo';

const overlay = new Container();
const selectedShape = new Container();
const gizmo = new TransformGizmo({
    mode: 'universal', // 'move' | 'rotate' | 'scale' | 'box' | 'universal'
    space: 'local', // move along the object's own axes, or 'world'
    snap: { translate: 10, angle: Math.PI / 12, scale: 0.1 },
    onChange: (t) => console.log(t.x, t.y, t.rotation, t.scaleX, t.scaleY),
});

overlay.addChild(gizmo);
gizmo.attach(selectedShape);
gizmo.state.mode.set('rotate');
```

- **Move.** The arrows lock to one axis, the centre square moves freely.
- **Rotate.** The ring turns the object about its pivot. The swept angle is shaded and read out
  in a pill, and snap ticks appear while snapping.
- **Scale.** Cube handles stretch one axis, the centre ring (or the corner cube in universal mode)
  scales evenly. Scale handles follow the object's own axes in both spaces.
- **Box.** Eight handles resize in the object's own frame while the opposite side stays put.
  Shift keeps the aspect, Alt resizes from the centre. The zones right outside the corners rotate
  the box about its centre.

Moving the gizmo to another object pops it. The old handles shrink away where they were, and the
new ones spring in group by group: arrows first, then the ring, then the scale handles. The gizmo
ignores the pointer until they land. `transition: 'glide'` slides the handles over instead.

Shift snaps moves to the grid, angles to 15 degrees and scales to steps. Set `snap.enabled` to snap
by default, and Shift then turns it off. Handles light up under the pointer, step back while
another one is dragged, and grow under a finger.

The gizmo writes the new transform into the target. Pass `apply: false` to handle it yourself in
`onChange`, for undo stacks or networked editors. `gizmo.grab(event)` starts a move from a press
on the object itself, so a click on an unselected shape can select and drag it in one gesture.

The box handles assume the object is not mirrored (positive scales).

## Selection outline

```ts
import { Container } from 'pixi.js';
import { SelectionOutline } from 'pixi-silk/ui/outline';

const [shape, shapeA, shapeB] = [new Container(), new Container(), new Container()];
const hover = new SelectionOutline();
const selection = new SelectionOutline({ dash: [5, 4], march: 16, padding: 4 });

shape.on('pointerover', () => hover.hover(shape));
shape.on('pointerout', () => hover.hover(null));
selection.select([shapeA, shapeB]); // one box around both
```

The hover style is a quiet line. The selected style has marching dashes and corner brackets.
Rotated objects get a rotated box, several objects one box around all of them. The frame follows
its objects exactly while they move.

When the selection changes, the old frame shrinks and fades where it was, its dashes and brackets
retracting, while the new frame springs in around the new objects. Pass `transition: 'glide'` to
slide one frame over instead.

## Smart guides

<Demo name="snap" height={380} caption="Drag a card. Edges, centres and the guide lines snap, and equal gaps show their size. Ctrl or Cmd turns guides off." />

`SnapEngine` is plain maths with no drawing. Give it rectangles, guide lines and points, and ask
where a moving rectangle should go:

```ts
import { SnapEngine } from 'pixi-silk/ui/snap';

const otherRects = [{ x: 0, y: 0, width: 100, height: 60 }];
const engine = new SnapEngine({ threshold: 6, targets: otherRects, lines: { x: [320] } });
const box = { x: 103, y: 40, width: 80, height: 60 };
const r = engine.snap(box);

box.x += r.dx;
box.y += r.dy;
```

It aligns edges with edges and centres with centres, and also offers equal spacing: centred
between two neighbours, or at a gap that already exists in the row. `SnapGuides` draws the
result, with dashed lines and gap sizes in pills. Each alignment fades in when found and out when
lost, so guides never slide from one alignment to the next. Hand both to a gizmo with `snapEngine` and
`snapGuides` and its free moves snap on their own.
