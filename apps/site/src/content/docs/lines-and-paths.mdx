## Lines and polylines

```ts nocheck
g.line(x0, y0, x1, y1).stroke({ width: 2, color: 0xffffff });
g.polyline([x0, y0, x1, y1, x2, y2]).stroke({ width: 3, color: 0x0a84ff, cap: 'round' });
g.polyline(points, { closed: true }).stroke(...);            // closed loop
g.polyline(points, { smooth: 'monotone' }).stroke(...);      // charts: never overshoots the data
g.polyline(points, { smooth: 'catmull' }).stroke(...);       // free curves through every point
```

Points can be a flat array `[x0, y0, x1, y1, ...]`, a typed array, or an array of `{ x, y }`.

A stroked path is one distance field. Every pixel is shaded once, so a translucent polyline has
uniform alpha at its corners instead of darker blobs.

## Joins

`join` sets how segments meet: `miter` (the default, as in Canvas and Pixi), `bevel` or `round`.
A miter longer than `miterLimit` half widths turns into a bevel. The default limit is 10.

<Demo name="joins" height={260} />

```ts
g.polyline(points).stroke({ width: 12, join: 'bevel', color: 0x0a84ff, alpha: 0.6 });
g.rect(0, 0, 80, 60).stroke({ width: 8, join: 'miter', miterLimit: 4 });
```

Joins follow Canvas 2D and SVG. Each segment is a butt rectangle, and the join fills the outer
corner. Caps apply at the open ends and at the ends of every dash. A dash that runs through a
corner gets the join too. Rects without a radius, triangles and stars without corner rounding
get sharp corners as well, so a stroked `rect()` looks like a Canvas one. Use `join: 'round'` for
the rounded outer corners of earlier versions.

A path stroke checks every segment of its path per pixel. Subpaths longer than 32 segments are
split into chunks, so long chart lines stay fast. Tapered strokes keep one capsule per segment.

## Paths

The canvas-style path API strokes and fills:

```ts
g.moveTo(10, 80)
    .quadraticCurveTo(60, 10, 110, 80)
    .bezierCurveTo(140, 120, 180, 20, 220, 60)
    .lineTo(260, 60)
    .stroke({ width: 3, color: 0xff9f0a, cap: 'round' });
```

Silk flattens curves adaptively into segments. A stroke draws the path as one outline. A fill draws the
whole path as one exact shape, so a bolt, a drop or a logo outline blurs, spreads and takes inner
shadows like a circle does. Overlapping subpaths follow the even-odd rule, so a square inside a
square makes a hole.

```ts
g.poly([64, 0, 6, 58, 44, 58, 30, 100, 94, 40, 56, 40]).fill({ color: 0xffd60a, blur: 12 });
```

Each fill checks every edge of its path per pixel. Keep paths to a few hundred points.

## Tapered strokes

Pass an array as `width`. With `[start, end]`, Silk interpolates the width along the path length.
With one value per point, each value sets the width at its vertex. Each segment becomes an uneven
capsule, so the taper is smooth through joints.

<Demo name="taper" height={240} />

```ts
g.polyline(points).stroke({ width: [2, 22], cap: 'round', gradient: along([0xff9f0a, 0xbf5af2]) });
```

`along()` is a gradient that follows the stroke from its first point to its last.

## Hairlines

Strokes thinner than one device pixel stay one pixel wide and fade in proportion. They do not break
up into dots. See [Fills & strokes](/docs/fills-and-strokes/#hairlines).
