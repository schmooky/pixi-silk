## Glass

`Glass` is a pane that reads whatever is already drawn behind it. It blurs it, bends it along the
curved rim, splits the colours where the rim is steepest, and catches light on the edge that faces
the light. Labels and icons go in `glass.content`, on top of the glass and sharp.

```ts
import { Text } from 'pixi.js';
import { Glass } from 'pixi-silk/glass';

const card = new Glass({ width: 300, height: 190, radius: 34, blur: 18, refraction: 16, dispersion: 0.4 });

card.content.addChild(new Text({ text: 'Frosted', style: { fill: 0xffffff } }));
card.set({ lightAngle: -Math.PI / 4, grain: 0.05 });
app.stage.addChild(card); // after the scene it frosts
```

The pane needs the canvas behind it, which WebGL keeps in a back buffer. `Glass` turns it on the
first time it draws, so the first frame shows a plain pane. Pass `useBackBuffer: true` to
`createSilkApp` to have glass from the first frame. On WebGPU the pane draws a frosted fill
instead. The pane stays axis aligned: scale it freely, but do not rotate it.

| Option | Default | What it does |
| --- | --- | --- |
| `blur` | 18 | Backdrop blur radius |
| `refraction` | 14 | How far the rim bends the backdrop (negative bends inwards) |
| `dispersion` | 0.35 | Colour split at the rim, 0 to 1 |
| `bevel` | 22 | Width of the curved rim |
| `frost` | 0.06 | Milky whitening, 0 to 1 |
| `saturation` | 1.2 | Colour boost of what shows through |
| `tint`, `tintAmount` | white, 0.04 | Coloured glass |
| `lightAngle`, `light` | top left, 0.8 | Where the sheen and the lit rim come from, and how bright |
| `grain` | 0.035 | Film grain |
| `shadow` | 0.3 | Soft shadow under the pane |

## Light that adds up

Light does not cover what is under it, it adds to it. Set `blendMode = 'add'` on a graphics (Figma
calls it Plus lighter) and overlapping glows burn towards white. Blur does the rest: every
`SilkGraphics` fill takes a `blur`, so a soft glow is one ellipse.

`Aurora` rises light from the bottom of a box in three colours and drifts slowly.

```ts
import { Aurora } from 'pixi-silk/glow';

const sky = new Aurora({ width: 200, height: 330, radius: 30, colors: [0x6f1bff, 0xee36ff, 0xffffff] });
```

## Neon

`Glow` draws one shape as a stack of passes. `neon()` is the five-layer Figma recipe for a shape
about `size` wide. Two blooms go behind. The core has a gradient, coloured drop glows and a pale
inner shadow. A 60% white copy added on top burns the middle out, and a blurred white outline
finishes it.
`bolt()` and `drop()` add ready outlines. Any path works, since fills treat it as one shape.

```ts
import { bolt, Glow, neon } from 'pixi-silk/glow';

const spark = new Glow({
    draw: (g) => bolt(g, -50, -70, 100, 140),
    layers: neon(0xffd60a, { size: 100 }),
});
```

## Beams, waves and slices

`ray()` adds a tapered beam, `fan()` spreads several from one point and `spectrum()` colours
them. Blurred and added, they make prisms, spotlights and hero lights. The hero below is three
pinched paths with blur 50, 27 and 12. The wave is a white stroke with red, orange and blue copies
a few pixels off. The bolt is one shape cut into strips, each smeared sideways.

## Stacked shadows

Several blurred copies behind a shape read better than one big blur: a tight one for the edge, a
wide one for the light. Each is the shape grown by its spread and blurred by half its CSS blur.
