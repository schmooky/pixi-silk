## Jog dial

```ts
import { JogDial } from 'pixi-silk/ui/dial';

const camera = { zoom: 1 };
const undo: number[] = [];
const zoom = new JogDial({
    radius: 64,
    turn: 2,          // value change per full turn
    step: 0.1,        // detents: the value clicks through steps
    min: 0.1,
    max: 8,           // past a limit it stretches and springs back
    onChange: (v) => (camera.zoom = v),
    onCommit: (v) => undo.push(v),
});
```

Press anywhere on the dial and drag around its centre. The value follows the angle and keeps
adding up over full turns, so there is no seam at the top. Past the ring the dial turns slower the
further out the pointer is: move out for fine control without letting go. `fine` sets how quickly
that happens, and 0 turns it off.

A fast release keeps the dial spinning and `friction` slows it down. With `min` and `max` the ring
becomes a gauge of the range, and one turn covers the range unless `turn` says otherwise. Past a
limit the dial stretches like a rubber band and springs back. A tap on the right half steps up, on
the left half steps down. `onChange` fires on every snapped change, `onCommit` once the dial rests.

## Scrub fields

```ts
import { Scrubber } from 'pixi-silk/ui/dial';

const size = new Scrubber({ label: 'Size', value: 24, step: 1, min: 1, max: 200, perPixel: 0.5 });
```

The number fields of 3D and compositing tools: drag sideways to change the value. Shift scrubs at
a tenth of the speed, and Ctrl or Cmd snaps to the step. A tap on either end steps down or up.
With `min` and `max` the field fills like a slider. A pill shows the value above the pointer while
dragging.

## Mini timeline

<Demo name="timeline" height={220} caption="Scrub, drag keys, box-select, move the loop handles. Tap the dial to pause." />

```ts
import { MiniTimeline } from 'pixi-silk/ui/timeline';

const timeline = new MiniTimeline({
    duration: 120,
    fps: 30,
    loop: [24, 96],
    keys: [{ id: 'jump', time: 30 }, { id: 'land', time: 44 }],
    onKeysChange: (keys) => localStorage.setItem('keys', JSON.stringify(keys)),
});

timeline.state.time.subscribe((frame) => console.log('frame', frame));
timeline.state.playing.set(true);
```

- **Scrub** the ruler. The playhead snaps to frames and stretches past either end of the track.
- **Keys** drag together when several are selected, snapped, and stop at the ends of the track.
  Shift-click adds to the selection, and a drag on empty track draws a selection box.
- **Loop range**: drag its green handles on the ruler. Playback wraps inside it.
- **Zoom** with the wheel around the pointer, pan sideways or with Shift. Pixi listens to the wheel
  passively, so the page scrolls too unless the canvas fills it. Without a wheel, a double tap on
  the ruler zooms in, and another zooms back out. `zoomBy`, `panBy` and `showAll` do the same from code.

State lives in `state`: `time`, `playing`, `selection`, `range` and `view`.

## Odometer

<Demo name="odometer" height={240} caption="Tap to add an amount. Tap again while it counts to skip to the end." />

```ts
import { Odometer } from 'pixi-silk/ui/odometer';

const balance = new Odometer({ value: 1250, decimals: 2, prefix: '$', fontSize: 44 });

balance.set(9800);       // counts up, longer for bigger jumps (speedUp)
balance.skip();          // straight to the end
balance.state.counting.subscribe((on) => console.log(on ? 'counting' : 'done'));
```

Every digit column rolls on its own. A column only moves while the one below it passes from 9 to 0,
so carries ripple like a mechanical counter. Each column holds two glyphs at most. Glyphs come
from a bitmap font made from the text style, so a frame only moves them, and one mask clips them all.
`format(value)` returns the same text without rolling, for labels and accessibility.
